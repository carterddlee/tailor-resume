## Question bank
When Carter asks for help answering an application question (e.g. "Why do you want to work here?"):
1. Check `question-bank.md` first for an earlier answer to the same or a similar question, and build on it.
2. Once Carter settles on a final answer, add it to the top of `question-bank.md` (newest first) using the same format: the question as the heading, then company / role, date, "Reusable for", and the answer text.
3. When Carter gives you an answer they wrote, save it word for word, typos included. Never save your edited version in its place. You can still suggest edits in chat, but only save them if Carter explicitly picks them.
